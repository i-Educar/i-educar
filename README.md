# i-Educar

Este repositório mantém uma linha independente de desenvolvimento do **i-Educar**, preservando compatibilidade e acompanhamento contínuo do projeto upstream.

O desenvolvimento upstream atualmente mantido pela Portábilis está disponível em:

https://github.com/portabilis/i-educar

## Estrutura das branches

* `main`: linha principal de desenvolvimento deste repositório.
* `upstream/*`: espelhos automáticos das branches correspondentes do repositório da Portábilis.

Exemplo:

```text
upstream/2.12
upstream/2.11
```

As branches `upstream/*` não recebem alterações próprias e servem como referência para acompanhar o desenvolvimento upstream.

Mudanças relevantes podem ser incorporadas à `main` após revisão e testes. Sempre que uma melhoria for genérica e aplicável ao projeto original, incentivamos sua contribuição também ao upstream.

## Sobre o projeto

O i-Educar é um software livre de gestão educacional, originalmente desenvolvido pela Prefeitura de Itajaí e posteriormente mantido e desenvolvido por diferentes pessoas e organizações ao longo de sua história.

Este repositório é uma iniciativa independente e busca contribuir de forma compatível e colaborativa com o ecossistema existente.
